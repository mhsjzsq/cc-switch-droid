CC Switch Droid Hook 2.2.4

入口：Open-Hook.cmd
完整说明：README.md
配置文件：config.json

2.2.4 增加首次配置窗口。没有 config.json 时，双击 Open-Hook.cmd，
选择包含 cc-switch.exe 的目录（或粘贴完整 EXE 路径），填写 Droid / Factory
API Key，然后点击“保存并启动”。Key 默认隐藏，两项均需填写。
配置自动生成后继续启动；取消不会创建配置或启动程序。
已有配置照常使用，不会自动覆盖；Key 的有效性由启动后的额度查询反馈。

2.2.3 将统计页顶部的长说明移到左侧 Droid 页“统计说明”折叠卡片。
默认收起，按记录、日期、费用和速度分项展示，刷新时保留展开状态。

2.2.2 针对应用显示开关变化，改为保留稳定的 Droid 导航按钮，
暂停监听自身界面修改、合并相关更新，并跳过应用页面的无关变化。
页面超时后重连并读取现有 Hook，不立即销毁并重复注入。
启动前在 data/settings-backups 保存原版设置副本；损坏 JSON 会阻止启动，
不会自动改写或恢复原设置，也不能代替原版运行中的并发保存修复。
本机原版实际版本为 4.0.12，程序所在目录名仍保留 v3.20.4。

2.2.1 补齐连续点击的取消保护，以及旧 Droid 内容层的清理。
点击 Droid / 全部直接切换原版筛选状态，不展开右侧下拉菜单。
重复点击 Droid 保持选中；不模拟菜单的鼠标或键盘操作，不隐藏页面。
保留取消过期筛选任务、保留侧栏 Droid 入口的处理。
2.1.0 为能唯一匹配本地请求日志的记录补全 tok/s 与首字耗时。
2.2.1 增加采样区间限制和歧义保护，减少相同 Token 数请求的错配风险。
用量记录是会话累计增量，不是每条回复，也不导入完整对话正文。
旧版估算耗时仍保留；无法可靠补全的新记录显示“—”。
原版 4.0.12 对 Droid 使用会话日志公式：输出 Token / 请求总秒数（含首字），
输出至少 200 Token、总耗时至少 1 秒才显示带“≈”的速度，否则显示“—”。
2.0.1 的隐藏 Claude 后左侧 Droid 入口修复也包含在内。
更新后请从托盘完整退出 CC Switch，再通过 Open-Hook.cmd 启动，
正在运行的旧助手不会自动读取更新后的界面代码。

使用前从托盘完整退出 CC Switch；如果旧版 Droid Addon 助手还在运行，
先停止旧助手并停用旧版的开机启动项。新入口会提示冲突，不会结束现有程序。

双击 Open-Hook.cmd 后，由本项目启动原版并加载 Droid 功能。
本目录已带 Python；不需要运行旧项目的 install.cmd。
本版本不写入开机启动项或 WebView2 注册表策略。

运行时有一个只服务本次 CC Switch 的会话助手。
从托盘完整退出原版后，助手完成取消和收尾后退出。
再次使用原版普通图标启动时，本项目不会自动介入。

如需移除：完整退出本次原版，等待助手结束，然后删除本目录与自己创建的快捷方式。
已经导入原版数据库的用量仍会保留。

config.json 含个人配置，分享项目时请不要打包该文件和 data 目录。
错误详情在 data/hook.log；本次启动状态在 data/launches 中。

本次仅编辑与阅读源码，没有打开配置窗口、运行程序、同步或测试，
也没有执行语法检查或哈希校验；2.2.4 的实际显示与运行效果尚未确认。
现有个人配置未改写；修改前源码在 data/first-run-setup-20261021-211811。
